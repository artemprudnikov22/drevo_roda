# Древо рода

Семейное исследование: Прудниковы, Воронко, Чертковы, Тарасенко.

Готовый отчёт: **https://artemprudnikov22.github.io/drevo_roda/**

## Что внутри

- `docs/` — публичный сайт с отчётом и сканами документов (его отдаёт GitHub Pages)
- `case/report.html` — исходный отчёт
- `case/*.csv` — реестры: люди, связи, документы, утверждения, места, журнал поисков
- `case/tree.ged` — родословная в формате GEDCOM 5.5.1
- `case/documents/`, `case/photos/` — сканы и фотографии архивных документов
- `case/source-atlas.md`, `case/research-state.md` — карта источников и очередь проверок

## Статусы надёжности

- **по документу** — есть скан с архивным шифром (ЦАМО и другие архивы)
- **по сведениям семьи** — записанный рассказ родственников, документа пока нет
- **версия** — рабочая гипотеза, требующая проверки
