## Примечания

- **Опознание.** Все сканы привязаны к человеку по ФИО, году рождения, части и архивному шифру. Для Черткова совпадение полное: 1909 г., 1109 сп 330 сд, призыв Кричевским РВК.
- **Расхождения.** У Тарасенко в карточке район рождения читается как Кличевский, в семейном рассказе — Кричевский. Вид награды по приказу 677/н не установлен: карточка называет Красное Знамя, на листе есть штампы о Ленине и Красном Знамени.
- **Рукописный текст** на сканах не расшифрован. OCR дал только фрагменты; нужен ручной разбор.
- **Где ещё могут быть снимки.** Семейные альбомы у Натальи, Татьяны Текучевой, детей Николая Воронко; личное дело В. В. Прудникова в ЦВМА.
